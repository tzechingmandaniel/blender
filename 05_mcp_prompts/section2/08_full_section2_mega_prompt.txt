MCP Mega Prompt §2.13 — Full Section 2 (Ready-to-Use)
======================================================

Use the existing Blender scene from Section 1. Create Section 2 blockout for a
non-functional AK-style exterior 3D prop.

Important safety and scope:
- This is only a visual exterior prop.
- Do not create internal firearm mechanisms.
- Do not create functional barrel, chamber, bolt, spring, trigger mechanism,

- All objects must be solid decorative exterior meshes only.

Use the locked side-view reference image and guide markers to match the

- dark wood for stock and handguards

Do not add small rivets, scratches, final textures, real mechanical openings,
or internal components yet. Focus only on proportion, silhouette, part
separation, and clean blockout volume.
