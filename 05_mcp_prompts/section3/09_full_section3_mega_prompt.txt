MCP Mega Prompt §3.19 — Full Section 3 (Ready-to-Use)
======================================================

Open v02_blockout.blend. Refine the BLK_ blockout objects into AK_ major
exterior parts for a non-functional AK-style exterior 3D prop. Save the
result as v03_major_parts.blend.

Important safety and scope:
- This is only a visual exterior prop.
- Do not create internal firearm mechanisms.
- Do not create a functional barrel, chamber, bolt, spring, trigger
  mechanism, firing system, detachable magazine system, or manufacturing-
  level details.
- All objects must remain solid decorative exterior meshes only.

Task — for each BLK_ object listed below, in order:
  1. Duplicate the object (object + mesh data).
  2. Rename the duplicate using the BLK_ → AK_ map.
  3. Move the duplicate to the matching sub-collection under 03_MAJOR_PARTS.
  4. Parent the AK_ object to AK47_MASTER_ASSET.
  5. Replace any pre-existing Bevel / WeightedNormal modifiers with the
     per-part bevel style from §3.18.2.
  6. Assign the single placeholder material listed.
  7. Move the original BLK_ into 03H_major_part_backup and hide it.
