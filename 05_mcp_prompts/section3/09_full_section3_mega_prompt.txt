MCP Mega Prompt §3.9 — Full Section 3 (Ready-to-Use)
=====================================================

Open the existing v02_blockout.blend (Section 2 result). Section 3 refines the
BLK_ blockout into AK_ major parts that define the prop's silhouette.

Important safety and scope:
- This is only a visual exterior prop.
- Do not create internal firearm mechanisms.
- Do not create functional barrel, chamber, bolt, spring, firing system,
  detachable magazine system, or manufacturing-level details.
- All AK_ objects must be solid decorative exterior meshes only.

Task:
Create eight refined AK_ major-part objects in the 03_MAJOR_PARTS collection.
For each part, start from a primitive that fills its proportion zone (§2.7.2),
add 1–3 loop cuts, then deform the silhouette to match the AK reference.
Apply a Bevel + Weighted Normal modifier stack and assign the placeholder
material per Section 1.

Objects to build:
 1. AK_receiver_main          (MAT_placeholder_dark_metal)
 2. AK_stock_main             (MAT_placeholder_dark_wood)
 3. AK_magazine_main          (MAT_placeholder_black_metal)
 4. AK_grip_main              (MAT_placeholder_bakelite_grip)
 5. AK_handguard_lower_main   (MAT_placeholder_dark_wood)
 6. AK_handguard_upper_main   (MAT_placeholder_dark_wood)
 7. AK_barrel_exterior_main   (MAT_placeholder_dark_metal)
 8. AK_dustcover_main         (MAT_placeholder_dark_metal)

Per-part silhouette refinements (high level — see §3.2..§3.8 for full detail):
- Receiver: shallow magazine-well + ejection-port indents (visual, not real
  openings), selector pad on +Y face.
- Stock: curved buttplate, cheek-rest slope, narrowed wrist, sling-slot
  silhouette recess on lower-rear (visual, NOT a real hole).
- Magazine: smoother banana curve across 4 subdivisions, two decorative
  raised side ribs, closed top (no opening).
- Grip: subtle concave front (finger relief), subtle convex rear (palm
  swell), tapered top, base cap flange.
- Lower handguard: front taller than rear, two shallow lower-face finger
  grooves (visual recesses), front collar band toward the barrel.
- Upper handguard: rounded top, small rear thumb-shelf raise.
- Barrel: slightly tapered toward the muzzle, decorative collar ring,
  closed muzzle disc.
- Dust cover: convex top profile, rear dip into stock wrist, small front lip
  toward the rear sight area.

Collection + assembly rules:
- All AK_ objects in 03_MAJOR_PARTS.
- All AK_ objects parented to AK47_MASTER_ASSET.
- Hide 02_BLOCKOUT in viewport and render — keep the file intact for
  reference, but Section 3 displays only the AK_ parts.
- Do NOT delete BLK_ objects. Section 3 carries the BLK_ sight/gas-block/
  front-ring/trigger-guard parts forward into Section 4.

Do not add rivets, panel lines, real openings, sling loops, working catches,
real magazine grooves, real screws, or final textures. Section 3 finishes when
the eight AK_ parts pass the §3.10 checklist (see section3_verify.py).

Save as v03_major_parts.blend at the same path as the v02 file.
