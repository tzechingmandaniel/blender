Fixes applied during Section 6 tuning iterations:
  - Reduced lookdev light energies (key 150W->30W, fill 60W->12W,
    rim 80W->15W) so dark blued metal reads dark, not chrome.
  - Reduced world background strength (0.45 -> 0.20) to stop bright
    environment reflections on metallic surfaces.
  - Raised EdgeWearMask CrispnessLow (0.40 -> 0.55) so Pointiness only
    fires on sharp edges; flat faces stay at base color.
  - Attenuated Noise/Wave influence on Base Color via multiplier
    (0.25 for metals/grip, 0.55 for wood) so flat surfaces dominate.
  - Darkened hero base colors and lowered grime factors so dirt tint
    no longer pushes materials toward neutral grey.
  - Pulled close-up cameras back (y=-0.18 -> -0.30/-0.32) and dropped
    lens (70mm -> 60mm) so each closeup frames its target object
    instead of zooming past it.
  - Forced grip metallic = 0 after build (grip uses metal builder for
    convenience but must NOT be metallic).
