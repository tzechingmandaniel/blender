# Advanced Presentation Pack — Phase 10

Public-facing portfolio, case study, and submission documents for the
non-functional AK-style exterior 3D prop. All plans here are **public-safe**:
no internal mechanisms, no working parts, no dimensions, no assembly
instructions.

> **Phase 10 status note.** These plans were drafted ahead of final render
> selection. They reference renders that live under `final_delivery/04_final_renders/`
> and `final_delivery/05_turntable/` — those paths will be populated when
> Sections 3–6 (major parts, detail, materials, final assembly) finish.
> Until then, the plans are scaffolding: the structure and wording are final,
> but the image filenames are placeholders.

## Where to start

1. Read `08_submission_pack/scope_and_safety_note.txt` — this is the
   non-negotiable scope.
2. Read `05_image_sequence/final_image_sequence.txt` — every other
   document references this order.
3. Pick a presentation surface and use its matching folder:
   - portfolio site → `01_portfolio_page/` + `02_website_case_study/`
   - ArtStation → `03_artstation_style_layout/` + `07_process_breakdown/`
   - social → `04_public_social_pack/`
   - reviewer / client → `08_submission_pack/`
4. Before publishing anywhere, run `10_publication_checklist/`.

## Stop rule

Phase 10 is presentation, not modelling. Do not create more planning phases.
If the model isn't complete, the next correct action is to resume Sections
3–6 in Blender — not to expand this folder.
