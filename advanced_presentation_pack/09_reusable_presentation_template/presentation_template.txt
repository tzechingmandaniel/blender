Reusable Presentation Template
For future non-functional exterior 3D prop projects
============================================================

HOW TO USE
----------
Copy this file into a new project's advanced_presentation_pack folder and
fill in the [bracketed] placeholders. Keep the safe-scope note as-is unless
the new project explicitly is a different type of asset.

TEMPLATE RULES
--------------
1. Replace [ProjectName] and [hero_image.png] with the new project's values.
2. Replace material close-up entries with the new material set.
3. Keep the safe scope note unless the new project is explicitly out of
   this template's scope (e.g. a non-weapon prop) — in which case rewrite
   the scope note for that asset type.
4. Remove object-specific wording from captions before reusing.
5. Keep all public-facing wording concise.
