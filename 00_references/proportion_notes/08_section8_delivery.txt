Section 8 Final Review / Packaging / Handover
==============================================

Section 8 takes the Phase 7 outputs (v07 + 14 stills + turntable frames +
3 exports + docs) and assembles a clean, self-contained final_delivery
package + final archive zip.

This is not a modelling phase — no geometry edits. The executor only
copies files, generates documentation, and (optionally) writes a final
.blend with relative texture paths.

§8.1 Source / output
--------------------
Input:  01_blender/v07_final_scene_export.blend +

        06_documentation/*  +  08_reviews/*

§8.7 Safety / scope reminders
-----------------------------
Every doc opens with the non-functional exterior visual prop scope.
No internal mechanism, working trigger, chamber, bolt, spring, firing
component, functional magazine, bore, rifling, manufacturing dimensions,
or real assembly instructions are referenced anywhere in the package.

§8.8 Texture path strategy
--------------------------
The Phase 6 shader graphs are fully procedural (Noise, Wave, Pointiness,
AmbientOcclusion, Wireframe shader node). They do not depend on external
PNG files. The 03_textures/<group>/README.txt files document the planned
PNG names so a future bake step (deferred to Phase 9) can drop maps into
the expected location. The final .blend opens with no missing-texture
warnings.
