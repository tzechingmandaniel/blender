Section 5 UV Planning + Material Setup + Texture Workflow Prep
================================================================

Section 5 turns the Section 4 model into a textur-ready model. It does NOT
paint final textures — that is Phase 6. It only:
  - groups objects by material type under 07_ASSEMBLY,
  - renames placeholder materials into the final MAT_* set (10 mats),
  - assigns final placeholder materials to every AK_ object,
  - unwraps every AK_ object so that texture direction is correct,
  - documents texel density, seam logic, and texture-map naming,
  - sets up the texture folder structure under 03_textures/.

Strictly exterior, strictly non-functional, no bore, chamber, working
trigger, manufacturing detail.

§5.6 UV seam logic
------------------
Receiver (box): seams along the bottom edges so the visible side panels read
as a single island. Top strip + bottom strip + L/R side islands +
front/rear caps.
Dust cover: single top island (front-to-back), seam at the lower edge.
Stock + handguards: cylinder/extrusion-style unwrap along +X (the long axis),
so grain runs lengthwise. Seam on the bottom (-Z).
Magazine (banana, curls along X-Z): seam on the rear spine, single curved
side island left/right, plus baseplate cap.
Grip (tilted -18°): seam along the front edge (least visible from side).
Barrel (cylinder along +X): seam on the bottom (-Z), single side island.
Small details: smart-projection at 66°, very small UV space share.

§5.7 Wood grain direction
-------------------------
Stock + lower hg + upper hg: U-axis must run along +X so painted/procedural
wood grain travels from butt to receiver / front to rear. UVs are rotated
accordingly after unwrap.

§5.8 Texel density target
-------------------------
Reference 1024 px per metre. Big surfaces (receiver sides, stock sides,
magazine sides, hg sides, grip sides, barrel cylinder) must be within
0.7×–1.3× of that density. Small details are allowed lower density.
