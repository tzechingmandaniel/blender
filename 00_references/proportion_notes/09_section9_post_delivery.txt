Section 9 Post-Delivery / Portfolio / Retrospective
====================================================

Section 9 takes the completed Phase 8 final_delivery and produces the
post_delivery/ folder: issue tracker template, minor-correction workflow,
version-update rules, portfolio case study, public wording guide, render
selection, workflow retrospective, reusable templates, next-project
recommendations, and an optional archive.

This is a documentation-only phase. No Blender. No model edits. No
renders. The executor runs as plain Python.

Strictly visual non-functional exterior prop. No internal mechanism, no
functional anything, no manufacturing dimensions.

§9.1 Source / output
--------------------
Input:  final_delivery/  (Phase 8 package)
Output: post_delivery/   + AK47_NonFunctional_Prop_post_delivery_YYYYMMDD.zip

§9.3 Reusable template strategy (§9.19)
---------------------------------------
Templates replace the project-specific name with the placeholder
ProjectName_NonFunctional_Prop. Weapon-specific wording is removed
unless it appears inside a scope disclaimer. The result is a generic
exterior-prop workflow toolkit that future projects can drop in.

§9.4 Portfolio selection (§9.13)
--------------------------------
6 stills + 1 MP4 are copied into 06_selected_portfolio_renders/:
  - hero 3/4
  - side profile
  - 4 material close-ups (receiver, wood, magazine, grip)
  - turntable MP4
A small portfolio_selection_notes.txt explains why each was chosen.

§9.5 Issue tracker template (§9.4)
----------------------------------
Empty post_delivery_issue_tracker.txt with 10-field format and 7
categories. Pre-populated with one informational entry so the file is
non-empty (PD_INFO_001 — "No post-delivery issues observed at handover").

§9.6 Public wording guide (§9.15)
---------------------------------
Three sections:
  - Safe wording (use these)
  - Avoid wording (do not use)
  - Rewrite examples (3 unsafe→safe pairs from §9.15)

§9.7 Workflow retrospective (§9.17)
-----------------------------------
Six sections answering: what worked, what caused problems, what to
improve, skills learned, what to reuse, what NOT to repeat.

§9.8 Next-project notes (§9.21)
-------------------------------
10 candidate non-weapon subjects + selection criteria + best-recommendation
section calling out weathered toolbox / vintage camera.

§9.9 Archive (§9.23)
--------------------
AK47_NonFunctional_Prop_post_delivery_YYYYMMDD.zip in project root +
copy in 09_archive/. DEFLATE 6. Excludes nothing (post_delivery/ is all
small text files; reasonable to zip everything).

§9.10 Safety / scope reminder
-----------------------------
Every text file in post_delivery/ opens with the non-functional exterior
visual prop reminder. The negation-aware forbidden-word scan from Phase
8 is reused so we catch unsafe wording immediately.
